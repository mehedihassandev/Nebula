# Nebula - Portfolio

Hi, I'm **Md. Mehedi Hassan**, a Frontend Developer specialising in React, React Native and Next.js.

This project is my personal portfolio. It's built to look and function like Visual Studio Code, giving a familiar and highly interactive experience for developers.

---

## Features

- **Explorer Sidebar**: Navigate files and projects. Click a file to open a preview tab, or double-click to pin it to your workspace.
- **Command Palette**: Press `Cmd + K` (or `Ctrl + K`) to search through all pages and projects instantly.
- **Integrated Terminal**: Open the terminal at the bottom to explore the site using commands.
- **File Previews**: Root files like `package.json` and this `README.md` render with full syntax highlighting and markdown parsing.

---

## Keyboard Shortcuts

To make this feel like a true IDE, I've implemented authentic keyboard shortcuts:

| Command              | Mac       | Windows / Linux |
| :------------------- | :-------- | :-------------- |
| **Command Palette**  | `Cmd + K` | `Ctrl + K`      |
| **Close Active Tab** | `Cmd + W` | `Ctrl + W`      |
| **Toggle Sidebar**   | `Cmd + B` | `Ctrl + B`      |
| **Toggle Terminal**  | `Cmd + j` | `Ctrl + j`      |

## Running Locally

If you want to run this project on your own machine:

1. **Clone the project:**

   ```bash
   git clone https://github.com/mehedihassandev/Nebula.git
   cd Nebula
   ```

2. **Install dependencies:**

   ```bash
   yarn install
   ```

3. **Start the development server:**

   ```bash
   yarn dev
   ```

4. **View the site:**
   Open your browser and go to `http://localhost:3000`.
